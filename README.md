# Heart Disease Prediction System

A machine learning course project. A Support Vector Classifier (SVC) predicts whether **heart disease is present** from just **4 input attributes**, and is deployed as a public web app with Streamlit Community Cloud.

Adapted from the Titanic Passenger Survival Prediction example, following the same steps (Import Libraries -> Load Data -> Pre-process -> Feature Extraction -> Train -> Test -> Application -> Feedback -> Deploy). **No label encoding is used** - all attributes are already numeric.

> Educational demo only. Not a medical tool - do not use it to diagnose anyone.

## Dataset

UCI Heart Disease Data Set, Cleveland subset (`processed.cleveland.data`, 303 patients). The original 0-4 target (`num`) is converted to binary: 0 = no disease, 1 = disease present.

## Inputs and Output

| Input | Meaning | Values |
|---|---|---|
| `sex` | Sex | 1 = Male, 0 = Female |
| `cp` | Chest pain type | 1 = Typical angina, 2 = Atypical angina, 3 = Non-anginal pain, 4 = Asymptomatic |
| `exang` | Exercise-induced angina | 1 = Yes, 0 = No |
| `oldpeak` | ST depression induced by exercise | 0.0 - 6.2 |

**Output:** `HeartDisease` - 1 = present, 0 = absent.

## Results

| Metric | Value |
|---|---|
| Accuracy (held-out test set, 61 patients) | 0.84 |
| Accuracy (5-fold cross-validation, mean) | 0.79 |

## Run Locally

```bash
python -m venv venv
venv\Scripts\activate          # Windows  (macOS/Linux: source venv/bin/activate)
pip install -r requirements.txt
streamlit run app.py
```

## Deploy to Streamlit Community Cloud

1. Push this folder's contents to the **root** of a **public** GitHub repository.
2. Go to https://share.streamlit.io and sign in with GitHub.
3. **Create app -> Deploy a public app from GitHub**: pick the repo, branch `main`, main file `app.py`.
4. Under **Advanced settings**, choose Python **3.11** or **3.12**, then click **Deploy**.

`scikit-learn` is pinned to the version that trained the model (1.8.0). If you retrain with a different version, update `requirements.txt` to match.
